Four useful local checks, now with a single-file download. / 四个本地工具，新增单文件下载版。

### Download and run

Download **offline-devkit.pyz** below. With Python 3.10+ installed, run:

```bash
python offline-devkit.pyz --help
python offline-devkit.pyz sizes . --top 5
```

No pip or third-party runtime dependencies. Use `py -3` on Windows or `python3` on macOS / Linux when needed. Downloading requires network access; running the tools is offline. SHA-256 is supplied in **SHA256SUMS.txt**. Source ZIP / tar.gz includes all examples.

### What's new

- **JSONL / NDJSON validation:** physical line numbers, strict UTF-8, duplicate-key and NaN/Infinity checks. Bounded record reads and error samples; incomplete reads remain explicit and return 2.
- **Portable archive:** about 10 KB, including Python sources, the entry point and MIT license. Python itself is required. Failure exit codes work outside the source directory.
- **Real-output demonstration:** exact JSON number spellings, bad JSONL records and read-only duplicate reports, with reproducible fixtures and Chinese / English instructions.
- **Directory replacement detection:** observed queued-directory replacements are skipped and reported as incomplete scans. Path-based checks retain concurrency limits.

The other tools remain available: strict JSON formatting, SHA-256 duplicate-file reports, and logical directory/file sizes. JSONL checks syntax and this tool's strict rules; it does not validate application schemas or provider-specific dataset requirements.

### Validation

65 behavior tests passed locally. The [five-environment CI run](https://github.com/lashonbakker-crypto/offline-devkit/actions/runs/38328161644) passed tests, installation, installed commands and portable builds on Linux / Python 3.10, 3.12, 3.14 and Windows, macOS / Python 3.12. Windows skips the FIFO test when `os.mkfifo` is unavailable. The release workflow runs the tests again and builds attachments from the tagged commit.
