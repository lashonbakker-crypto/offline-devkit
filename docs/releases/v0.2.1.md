# Offline DevKit v0.2.1

## 中文

- 单文件下载包包含已修复的 JSON 重复 UTF-8 BOM 检查：允许开头一个 BOM，连续两个或更多 BOM 返回 2，不输出格式化内容；数字原文保留正常。
- 增加 [Bash / PowerShell JSONL 管道教程](https://github.com/lashonbakker-crypto/offline-devkit/blob/v0.2.1/docs/04-jsonl-pipelines.md)、合成生成器和可执行脚本。分别保留生成器和校验器退出码，避免把中途停止的数据误当成完整业务结果；明确 UTF-8 编码。
- CI 在实际 shell 中检查有效数据、中文重复键、生成器失败，以及行号、计数和示例文件未改动。原有 66 项行为测试继续覆盖 CLI、JSON / JSONL、文件扫描和单文件包。

下载 `offline-devkit.pyz` 与 `SHA256SUMS.txt`。需要 Python 3.10+，无需 pip：

```bash
python offline-devkit.pyz --version
python offline-devkit.pyz jsonl records.jsonl --json
```

文件命令保持只读。JSONL 校验不验证业务 schema；`complete=true` 表示读到当前输入末尾，不表示生成器成功。

## English

The portable download now includes the repeated UTF-8 BOM fix for JSON input. One prefix is accepted; repeated prefixes exit 2 without formatted output. Exact numeric tokens remain supported.

New [tested pipeline recipes](https://github.com/lashonbakker-crypto/offline-devkit/blob/v0.2.1/docs/04-jsonl-pipelines.en.md) for Bash and PowerShell retain both producer and validator exit codes, use explicit UTF-8, and demonstrate valid input, a duplicate key, and a producer failure. CI checks the real shells, record counts, line numbers, and unchanged examples alongside the existing 66 behavior tests.

Download `offline-devkit.pyz` and `SHA256SUMS.txt`. Python 3.10+ is required; pip is not. File commands remain read-only. JSONL validation does not check business schemas or establish that a producer emitted its intended dataset.
