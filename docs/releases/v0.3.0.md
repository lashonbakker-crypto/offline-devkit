# Offline DevKit v0.3.0

## 中文

单文件下载包现在包含 `dupes --verify-bytes`：先按大小和 SHA-256 筛选，再对同哈希候选分块逐字节比较。适合希望对重复内容增加一次直接复核的本地资料与备份检查。

```bash
python offline-devkit.pyz --version
python offline-devkit.pyz dupes ./Downloads --verify-bytes --json
```

第一条输出 `offline-devkit 0.3.0`。第二条报告 `verify_bytes: true`，真正归入重复组的文件标记 `verified_by: "bytes"`；`byte_comparisons` 是执行的候选文件比较次数。默认仍使用较快的 SHA-256 路径，追加 `--fail-if-found` 可在发现重复时返回 1。

- 模拟哈希碰撞的回归测试确认不同字节不会被误归为重复；归档测试同时验证新参数在源码目录外生效。
- 包含此前的重复 BOM 修复，以及分别保留生成器与校验器状态的 Bash / PowerShell JSONL 管道示例。
- 下载同一版本的 `offline-devkit.pyz` 与 `SHA256SUMS.txt`，按[校验说明](https://github.com/lashonbakker-crypto/offline-devkit/blob/v0.3.0/docs/publishing.md)核对。

需要 Python 3.10+，无需 pip，运行时无第三方依赖。文件命令只读，不删除文件。额外复核会增加读取量，扫描仍不是文件系统快照；逻辑大小不等于可以回收的磁盘空间。

## English

The portable archive now includes `dupes --verify-bytes`. Size and SHA-256 filtering remain the default; this optional mode compares same-hash candidates in bounded byte chunks before reporting them as duplicates.

The JSON report includes `verify_bytes`, `byte_comparisons`, and per-group `verified_by: "bytes"`. Tests inject equal hashes for different contents and check the new option in an isolated portable archive. Previous JSON BOM fixes and the Bash/PowerShell JSONL pipeline recipes are included.

Download both assets from this release and [verify the checksum](https://github.com/lashonbakker-crypto/offline-devkit/blob/v0.3.0/docs/publishing.md). Python 3.10+ is required; pip is unnecessary. File commands remain read-only. Byte verification adds I/O and does not turn a scan into a filesystem snapshot.
